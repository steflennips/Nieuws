# Nieuws voor Deux2qonnect

Een overzicht van het nieuws over **BI, Data, Automatisering en AI**, speciaal voor Deux2qonnect. Alles op een plek, elke dag ververst.

**Bekijk de site:** https://steflennips.github.io/Nieuws/

## Wat vind je op de site?
- **Overzicht**: bovenaan Uitgelicht (de belangrijkste recente koppen), daaronder tellers per categorie en het blok Vaknieuws met de nieuwste items.
- **Nieuws**: alle artikelen op een rij. Filter op BI, Data, Automatisering of AI, of zoek op een woord.
- **Bronnen**: de lijst van alle bronnen waar het nieuws vandaan komt.

## Waar komt het nieuws vandaan?
Uit openbare RSS-feeds van onder meer:
- Computable, Emerce, Techzine en NOS Tech (algemeen Nederlands nieuws)
- Power BI Blog en Microsoft Fabric Blog (Microsoft), SQLBI
- Microsoft Power Platform Blog (Power Automate), Camunda Blog en n8n Blog (automatisering)

Per artikel tonen we alleen de kop, een korte samenvatting en een link naar de bron. Volledige artikelen staan hier niet: wil je meer lezen, dan klik je door naar de oorspronkelijke site. Alle rechten blijven bij de bronnen.

## Hoe vaak wordt het ververst?
Elke dag, ongeveer om 06:00 (Nederlandse tijd). Onderaan de site zie je wanneer de laatste verversing is gelukt. Nieuws blijft ongeveer 60 dagen staan.
